🛠 질문 제작소

  1. 카테고리와 질문 유형을 골라요.
  2. 질문 내용과 만든 사람을 적고 ‘생성하기’를 눌러요.
  3. 이모지로 카드를 예쁘게 꾸며요.
  4. ‘공유하기’로 모두의 카드에 더하고, ‘내보내기’로 친구에게 보내요.

🧭 질문 탐험대

카테고리와 유형을 골라 한 번에 여러 장을 무작위로 뽑아요.

🎰 질문 로또

버튼 한 번에 무작위 한 장을 만나요. 카드를 클릭하면 뒤집혀요.

💾 입력 내용은 자동 저장돼요. ‘초기화’로 한 번에 비울 수 있어요.

🌐 한국어 · English · 日本語 — 언어를 바꾸면 카드 내용도 자동 번역돼요.
