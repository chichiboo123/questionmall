01 💡

왜 ‘질문 다있소’인가요?

좋은 답보다 좋은 질문이 어린이의 세계를 넓혀줍니다. ‘질문 다있소’는 아이들이 직접 만든 질문을 카드로 모아, 교실·가정·동아리에서 누구나 꺼내 이야기할 수 있게 해주는 작은 도구예요.

초등 교실 가족 대화 상담 · 동아리 3개 언어
02 🛠

질문 제작소

카테고리·유형·색깔·이모지까지 골라 나만의 카드 한 장을 완성해요.

  • 마음 · 생각 · 몸 · 관계 · 기타
  • 736개 이모지 + 직접 입력
  • 입력 자동 저장 · 초기화 버튼
  • JPG 저장 / 클립보드 복사
03 🧭

질문 탐험대

오늘 하고 싶은 주제를 골라, 한 번에 여러 장을 무작위로 뽑아 책상에 펼쳐 봐요.

  • 카테고리 · 유형 다중 필터
  • 1~30장 한꺼번에 뽑기
  • ‘모두 뒤집기’로 동시 공개
04 🎰

질문 로또

한 명씩 돌아가며 단 한 장의 질문을 만나는 ‘오늘의 질문’ 타임.

  • 버튼 한 번에 무작위 1장
  • 연속 중복 자동 방지
  • 카드 클릭 → 앞·뒷면 플립
05 🎨

꾸미는 즐거움

8개 팩 · 736개 이모지 · 최근 사용 16칸 · 직접 입력까지. 카드 한 장이 곧 어린이의 작은 작품이 됩니다.

  • 표정 / 손짓 / 자연 / 음식 / 동물 / 활동 / 사물 / 기호
  • 7색 파스텔 팔레트
  • 세리프 따옴표가 만드는 ‘책 같은’ 카드
06 🌐

3개 언어, 자동 번역

한국어로 만든 카드를 영어 · 일본어로 바꿔도 그대로 읽혀요. UI는 i18n 사전으로, 카드 본문·라벨은 구글 스프레드시트의 GOOGLETRANSLATE 수식으로 자동 번역돼 시트가 캐시와 갱신을 처리합니다.

한국어 English 日本語 실시간 전환
07 💖

공유 전 한 번 더

공유하기 버튼을 누르면 어린이 친화 안내 모달이 한 번 더 떠요.

  • 공유 후엔 수정·삭제할 수 없어요
  • 맞춤법은 한 번 더 살펴보기
  • 친구의 마음을 다치게 하는 말이 없는지 확인
08 ⚙️

가볍게, 정적으로

서버나 빌드 도구 없이 HTML · CSS · JS 정적 파일 + 구글 시트만으로 동작해요. 학교·가정 환경에서도 무리 없이 켤 수 있는 가벼움.

  • HTML / CSS / JS (의존성 단 한 개: html2canvas)
  • Google Apps Script Web App 백엔드
  • localStorage 자동 저장
